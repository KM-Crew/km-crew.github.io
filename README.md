# KM-Crew 아이디어 10 (허브)

하입소문 서비스 공모전 후보 10개 프로토타입을 **한 창에서** 보는 사이트입니다.

- 주소: https://km-crew.github.io/
- 목록 → 카드 클릭 → 상세(체험 화면 + 기획서·회의 점수)
- 상세에서 **📱 모바일 / 🖥 PC** 전환: 모바일은 휴대폰 틀, PC는 1280×800 브라우저 틀(축소 표시). 각 앱이 틀의 폭에 맞춰 PC·모바일 배치를 바꿈. 전환·크게 보기를 해도 iframe을 옮기지 않으므로 진행 상태가 유지됨
- 체험 화면은 같은 사이트의 `/<저장소>/`를 iframe으로 넣어서 새 창이 열리지 않습니다. "크게 체험"도 같은 창 안의 전체 화면입니다.
- 기획서는 각 저장소의 `PLAN.md`를 그대로 불러옵니다(공통 조건 절은 생략).
- 회의 점수(재미·쓸모·완성 가능성 + 메모)는 보는 기기의 브라우저에만 저장됩니다.
- **회의 모드** `#/meet`: 별명을 적고 "내 점수 링크"를 만들어 메신저로 보내면, 받은 사람이 링크를 열어 "합치기"로 한 표에 모읍니다. 서버 없이 링크(`#/meet?d=`) 안에 점수만 담기며(별명 12자·메모 120자, 값 검사), 평균·순위(🥇🥈🥉)·점수 차 5 이상 '갈림'·메모 모아 보기를 보여 줍니다. 합친 점수는 목록 카드·상세·비교표의 '팀 평균'에도 나옵니다.
- **한눈에 비교**: 표 머리글을 누르면 번호·이름·난이도·점수·합계·팀 평균으로 정렬(다시 누르면 반대).
- 목록 카드에는 각 앱의 OG 썸네일(`/<저장소>/og.png`)이 나오고, 불러오지 못하면 색 바탕으로 대신합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 뼈대 |
| `ideas.js` | 10개 아이디어 목록(제목·한 줄 소개·난이도·노릴 상·걸리는 점) |
| `hub.js` | 목록·상세·비교 화면, 크게 보기 |
| `hub.css` | 스타일 |
| `og.png` | 허브 링크 미리보기 이미지(1200×630) |

아이디어를 추가·수정하면 `ideas.js`만 고치면 됩니다. 각 서비스 코드는 개별 저장소에 있습니다.
