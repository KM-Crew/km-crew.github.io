# KM-Crew 아이디어 10 (허브)

하입소문 서비스 공모전 후보 10개 프로토타입을 **한 창에서** 보는 사이트입니다.

- 주소: https://km-crew.github.io/
- 목록 → 카드 클릭 → 상세(왼쪽: 체험 화면, 오른쪽: 기획서·회의 점수)
- 체험 화면은 같은 사이트의 `/<저장소>/`를 iframe으로 넣어서 새 창이 열리지 않습니다. "크게 체험하기"도 같은 창 안의 전체 화면입니다.
- 기획서는 각 저장소의 `PLAN.md`를 그대로 불러옵니다(공통 조건 절은 생략).
- 회의 점수(재미·쓸모·완성 가능성 + 메모)는 보는 기기의 브라우저에만 저장됩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 뼈대 |
| `ideas.js` | 10개 아이디어 목록(제목·한 줄 소개·난이도·노릴 상·걸리는 점) |
| `hub.js` | 목록·상세·비교 화면, 크게 보기 |
| `hub.css` | 스타일 |

아이디어를 추가·수정하면 `ideas.js`만 고치면 됩니다. 각 서비스 코드는 개별 저장소에 있습니다.
